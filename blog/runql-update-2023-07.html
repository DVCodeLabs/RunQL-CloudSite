July Product Update: SSH Support, Smarter Query Logs, and Workspace UX

runQL Team • July 2023

Keeping your data secure, your queries smarter, and your workspace smoother—that’s what July was all about.

From SSH tunneling for MySQL and Redshift, to an all-new history log experience, to better workspace permissions, we’re leveling up your SQL workflow at every turn.

History Logs and Auto Suggest Enhancements

  • Fully redesigned History Log page with search, filters, and version toggles
  • Sharper autosuggestions for faster, more accurate querying

SSH Support for Secure Connections

  • MySQL and Redshift connections now have the option for SSH tunneling
  • UI updates to handle SSH credentials in both Add and Edit connection modals
  • Default values for supported DBMS types added

Query Improvements & Parsing Upgrades

  • Support for non-SELECT MySQL queries like INSERT, UPDATE, and DELETE
  • Smarter SQL parsing and error handling across saved queries and logs
  • "Use Query" button fix—now opens in the correct tab every time
  • Saved query versioning includes full history

Workspace Collaboration & Permissions

  • Collaborator icons and recent activity now visible in workspace logs
  • Fine-tuned role management and clearer permission settings
  • Streamlined workspace creation with badges and smart defaults

Performance Improvements

  • Improved password change flow and validation
  • Auto-resizing columns for data results—for readability
  • Spinners for loading states and smarter Run button behavior
  • Performance improvements for workspace rendering and tabs

We’re getting closer to our vision: a query platform built for analysts, not developers.

— The runQL Team
