Product Update: BigQuery + Auth, Analyst AI & UX Polish

runQL Team • September 2025

This month we're shipping major updates for BigQuery users, powerful new workflows for Analyst AI, and a host of UX improvements to make your daily work smoother.

Sept 2025 Shipping Themes

  • BigQuery + Auth
  • Analyst AI/Business Answers
  • UX polish

Integrations & Auth

We've doubled down on Google BigQuery support and simplified authentication:

  • BigQuery OAuth: Improved OAuth support and better defaults for a seamless connection experience.
  • Nested Data: Significantly better display for BigQuery nested/RECORD types.
  • Validation: Multiple fixes for BigQuery query validation.
  • WorkOS Migration: Ongoing migration to WorkOS for robust authentication and stability fixes.

Analyst AI & Query Generation

Empowering analysts to generate better queries faster:

  • Parameterized Queries: Analyst queries can now be fully parameterized.
  • Assistant UI: A new Analyst AI assistant interface that supports “general + schema” questions.
  • Quality Control: Improved controls for judging and rewriting generated queries.

Collaboration & Admin

  • Better handling for closed threads.
  • Real-time progress updates for replies.
  • Improved notification counting for archived threads.
  • Org-admin visibility into threads they’re not a member of.

Product UX

We've polished the experience across the board:

  • Multiple UI polish items across tabs and version history.
  • Results table usability improvements (handling large number columns, resize stability).
  • Cleaner styling for Cards and simpler empty states.
