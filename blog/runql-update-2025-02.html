February 2025 Product Updates

runQL Team • February 28, 2025

Hey everyone! This past week was a lot of clean up and refinement to make your query work faster, smoother, and smarter.

New and Improved

  • ❄️ Snowflake Oauth – You can now use Snowflake Oauth for your credentials when connecting from runQL.
  • Link Sharing – You can now share links to queries in the desktop app. The web app always had this capability.
  • Query Review Pages – We've made it easier for you to work with Schema Changes and Query Certifications. You now only see one query item at a time instead of being overwhelmed with them all at once.
  • ✨ runQL AI – You now have more room for conversations with runQL AI and for reviewing information. You now access runQL AI via the star icon in the top right hand corner which reveals a right panel. The right panel can also be expanded to the full screen width for consuming large amounts of information when working through actions like Query Optimization.
  • Business Answers Chat (MVP - Updates) – Get fast, trusted insights from analyst-approved queries. We've cleaned up the MVP version of natural language chat for business users - The left hand requests area has been cleaned up along with the chat interface.
  • ✅ New Save Button – Now when you click save it is automatically shared with everyone in your workspace. If you want to keep a query private then click the down arrow beside save. You can now also duplicate and revert from the dropdown save button.
  • Query Cards – We've updated the query cards to make the query more readable and easier to copy.
  • Query Tab – You now have suggestions, parameters and data results visible by default with the other items in the dropdown menu. This cleans up the bottom panel bar. Soon Documentation and Requests will move to the right hand panel with the AI chat to give you more room to read and interact with the content.

Bug Fixes

  • Workspace saved query count has been corrected.
  • PostgreSQL Data Catalog issue.
  • Minor security enhancements.
  • Business Answers - Handle queries that have been deleted.
  • Snowflake query results omit values when joining tables with same column names.
  • Syntax highlighting in the query cell was broken for a few hours. It's back in full techni-color.
  • RunSource button not updating UI to show runSource configuration.
  • Analyst Description could not be applied from the new AI right panel.
  • Query Optimization Explain could not be used in the new AI right panel.
  • Query editor suggestions cut off.
  • Tab open query parameter error.
  • Fix for Optimize Query execution plan step.
  • Fix for query card title and icon alignment in business answers.
  • Fix for refreshing schemas in Navigator - it would refresh all schemas.
  • Fix for save button on visible schemas tab causing all schemas to refresh.
  • Fix for keyboard shortcuts in Query Editor.

That’s it for now! Try out the new features and let us know what you think.

— The runQL Team
