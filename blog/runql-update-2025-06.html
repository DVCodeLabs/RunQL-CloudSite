June 2025 All Product Updates

runQL Team • June 30, 2025

✨ dbt Metrics Layer Integration, more deterministic workflows, better intent detection, and user experience updates!

  • dbt-powered Metric Layer integration is now generally available for all runQL customers
  • Business Users can customize charts, pin answers, and archive chats
  • Data Analysts can test Business User experiences using role toggles in the Data Analyst Studio
  • Multitasking just got easier with tab context memory and overflow menus in Data Analyst Studio
  • Smarter AI assistance through improved intent detection, updated query ranking, and updated sub-query validation
  • Plus: fixes for Snowflake foreign key relationships and shared DB connection testing

dbt Metric Layer IntegrationNew

We're thrilled to announce that the dbt Labs Metric Layer integration is now available to all customers in runQL bringing another trusted step into our deterministic query workflows. For customers using dbt, this latest release is in addition to the existing integration, which syncs the dbt Semantic Models with the runQL automated Semantic Models.

When a business user asks a question in runQL, we first check the existing verified query library, then we check for verified dbt metrics as part of the answer path before entering data analyst workflows or generating anything with AI. That means more answers are grounded in verified, deterministic logic built by your analytics team, and fewer ad hoc requests land on data analysts’ desks.

Why it matters:
✅ Business users get faster, trusted answers
✅ Data teams reduce repetitive requests
✅ Organizations using dbt can now extend their investment into runQL's chat-based UI

Not using dbt?
We're building the cube semantic layer (open source) into runQL as a default offering to bring this same deterministic approach to all users, no matter your stack!

We're here to help your business get faster, trusted insights, and enable data teams to move faster while reducing repetitive requests.

Data Analyst IDE - Testing New

Data Analysts can now toggle between a Business User role and Data Analyst role to test the Business User experience.

Conversational Charts New

In addition to the instant charts we already provide, Business Users can now update charts directly in the conversation flow.

Pinned Answers New

Business Users can easily pin previous answers for quick access.

Chat Archive New

Both Business Users and Data Analysts can now archive chat threads and toggle between their archived and current threads.

AI-Generated Queries - Schema Change Resolution New

Schema updates now trigger version updates to AI-generated queries. This is the same process as schema change resolution for Data Analyst approved queries.

Deterministic Workflows Update

We’ve added more deterministic workflows for saved queries and dbt with smarts about when to check for dbt metrics layer answers.

Analyst Studio (IDE) AI Assistant. Update

We've updated the AI Assistant for Data Analysts - they now get existing query suggestions in the conversation thread.

Better Intent Detection Update

Business and Data Analyst AI chats now better understand user intent from the chat thread history.

Multitasking Updates - Data Analyst Studio (IDE) Update

Each tab now preserves its own chat context making multitasking way easier. Also there's a new dropdown at the end of the tabs row that shows all tabs that are outside of what's visible in the UI.

Answer Ranking Update

We've updated the automated algorithms and workflows for better ranking accuracy.

Sub-Query Validation Update

We've updated the sub-queries validation checks to capture more use cases.

Snowflake Relationships Fix

We fixed an issue with Snowflake connections not pulling in foreign key constraints.

Connection Tests Fix

We’ve resolved the bug preventing the testing of shared database connection after a password change.
