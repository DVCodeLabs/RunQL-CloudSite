August Product Update: Snowflake Support, Role-Based Access & Smart Query Suggestions

runQL Team • August 2023

❄️ Snowflake Integration

  • runQL now supports native Snowflake connections — from query execution to schema reading
  • Fixes for nullable fields, smoother error handling, and efficient connection reuse

Role-Based Access Control (RBAC)

  • Enforce granular permissions across workspaces, queries, connections, and logs
  • Control who can edit, save, run, or view items in a workspace
  • Admins manage roles from a new console. Workspace owners control access via the workspace admin console

AI-Powered Query Suggestions & Tagging

  • Full query autosuggestions now powered by OpenSearch + usage metadata
  • Saved queries support both user-defined and system-generated tags
  • Saved queries are indexed instantly — even if not run yet

Editor & Workspace Upgrades

  • Redesigned tabs with line wrapping and improved structure
  • Clearer, more actionable error messages

Data Connections & Query Log Enhancements

  • Each data connection now shows description and full config options
  • Query logs searchable by table name, user, database, and date
  • Global vs. workspace-level views now consistent and consolidated

AI-Assisted Metadata & Intelligence

  • Saved queries get automatic titles and descriptions thanks to AI
  • Click tracking on "Use Query" and suggestions to improve metrics and personalization
  • Improved tagging UI and metadata editing experience
