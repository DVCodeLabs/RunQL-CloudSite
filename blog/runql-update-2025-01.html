January 2025 Product Updates

runQL Team • January 31, 2025

Hey everyone! We've been busy shipping updates to make your query work faster, smoother, and smarter. Here’s what’s new.

New Features

  • Business Answers Chat (MVP) – Our first version of natural language chat for business users is here! Get fast, trusted insights from analyst-approved queries. More on this coming soon!
  • SSH Tunneling for More Databases – Now supported for Postgres, MSSQL, Oracle, and Redshift.
  • ⏳ Session Credentials – Choose to have your credentials expire when your session ends for added security.
  • Schema Metadata in Navigator – See data catalog items, synthetic schema data, and descriptions right in the Navigator.

✨ Improvements & Optimizations

  • Query Editor Tweaks – Pressing Tab now only moves the cursor (no more full-line tabs!), and autocomplete now works with Tab by default.
  • Data Results Table – More room for column names. Hover to reveal the column actions.
  • AI Enhancements – More consistent responses across documentation, optimizations, and charts.
  • Better Search & Filters – Finding queries is faster! My Saved and Workspace Saved tabs are now merged, with new filters to refine results.

Speed & Usability Tweaks

  • Faster schema loading when adding new connections.
  • Auto-complete for connection details (goodbye, retyping long hostnames!).
  • Traffic compression for faster data results.
  • Query tab behavior: If you open a query that’s already in a tab, you’ll jump to the existing tab instead of opening a duplicate.
  • Editing tables UI update – Deleting columns is now clearer.

Bug Fixes

  • Fixed issues with query log cards and dangerous query notifications.
  • Multiple search fixes and workflow data result scrolling issues.
  • Deleted tables now properly refresh in schemas.

That’s it for now! Try out the new features and let us know what you think.

— The runQL Team
