April 2024 Product Updates

runQL Team • April 30, 2024

In April we added snippets, autosaved drafts, role-based CSV controls, and smart workflow documentation — plus major performance upgrades and fixes. Here's everything that shipped!

April 30, 2024

Snippets New

Highlight any SQL and quickly add it to your snippets for easy reuse in any other query.

  • Save and reuse SQL snippets across queries
  • Boosts speed when writing complex queries

Autosaved Drafts New

Query drafts are auto-saved so you never lose work-in-progress. Drafts are private and can be found in three places: "My Queries" on the home page, workspace drafts in "My Queries" in the sidebar, and drafts for a particular query under "My Drafts" for that query.

  • Protects your work with automatic draft saving
  • Drafts are private and easily accessible

Disable CSV Downloads New

For organizations that want to disable CSV downloads of data. There is now an option to disable downloads for each role type on the Accounts page under Security Options.

  • Control CSV download permissions by role
  • Improves data security and governance

Workflow Documentation New

Workflows now get documentation for all steps in the workflow.

  • Generates documentation across entire workflows

Workflow Search Update

All steps in a workflow are now indexed in search.

  • Find workflows faster via search

AI Documentation Update

- The title, description, and inline comments are now automatically regenerated for each new query version. This will always happen unless you manually edit one of the fields, in that case the field you edited is preserved.
- AI Documentation is saved per versioned query now so you can see the history of documentation.

  • Regenerates documentation with every new query version
  • Manually edited fields are preserved
  • Full history of documentation now available per version

View Comments Update

Any comments in a suggested query are hidden until you expand the window. This is to allow you to see more query context.

  • Streamlined query view by hiding comments until expanded
  • Prioritizes showing full query content first

Add Data Connections Update

Adding a data connection now has a new wizard to make the process easier. Databases are now treated the exact same as data warehouses where you can select multiple schemas per connection.

  • New guided wizard for setting up connections
  • Multi-schema support for all databases and warehouses

Workspace Connections Update

When opening a new workspace without a data connection, you are now prompted to add a connection.

  • Friendly prompt to add connections upfront
  • Smoother workspace setup experience

Performance Improvements Update

We made some changes to significantly improve performance in workspaces with a large number of queries.

  • Faster load times when working with a large number of queries

Syntax Autocomplete Fix

Deployed a syntax autocomplete fix for MS SQL, BigQuery, and Databricks.

  • Fixes autocomplete for multiple database engines
  • Improves overall query writing experience

Query Editor Fix

Deployed a fix for the query editor which would auto flip between auto formatted and collapsed whenever you click run. Now it just auto formats the way it is supposed to!

  • Fixes formatting toggle behavior in query editor
  • Ensures consistent formatting on query run

What we're working on next

  • A browser extension that allows you to quickly search and grab any of your saved queries from runQL while working inside any BI tool.
  • Automatic schema metadata and synthetic data generation to increase documentation accuracy and business user search performance.
